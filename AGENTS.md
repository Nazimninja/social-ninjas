### Key Rules at a Glance:
1. **Never claim offline support**: App requires active connectivity (Supabase auth, remote exercise media, cloud sync).
2. **No AI hype/buzzwords**: Position as elite coaching and athletic tracking. Never use cheesy "Magic AI" claims.
3. **Color discipline**: Obsidian dark base (`#0c0c0e`, `#101116`), Electric Sky Blue (`#38bdf8`) accents, Slate/Carbon cards, Green (`#22c55e`) strictly for completed sets.
4. **Layout discipline**: 1140px main container, 800px text container. Locked for 100% zoom.
5. **Pricing**: ₹99 first month introductory hook, ₹399/mo ongoing renewal, ₹0 Starter Pass.
6. **Company Contact**: Strictly `info@socialninjas.in` on all public pages, tools, and code. Login / GBP under `nazim.socialninja@gmail.com`.
7. **SEO Head Terms**: Never target head terms (`take home pay calculator`, `mortgage calculator`) head-on against entrenched giants; target long-tail, wage tiers ($20, $25, $30, $35/hr), and state tax variants.
8. **Brand Defense**: Defend exact brand & domain queries (`socialninjas.in`, `social ninja's agency`) — never chase generic game/entertainment keywords.
9. **Zero AI Filler**: Every post must target 1 verified keyword, satisfy 1 search intent, and conclude with a specific service/tool CTA.
10. **Zero Link Schemes**: Never buy links or use PBNs. Build authority via data studies, tool embeds, directory listings, and genuine digital PR.
11. **Cadence Discipline**: Minimum 2 strategic posts/month to prevent algorithmic decay. Run Rich Results Test on all new pages.
