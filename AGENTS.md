# Project Instructions & Agent Guidelines

See [GEMINI.md](file:///D:/Social%20Ninja's/projects/social-ninjas/GEMINI.md) for full project memory, architecture, tech stack, design standards, and integrations.

### Key Rules at a Glance:
1. **Never claim offline support**: App requires active connectivity.
2. **No AI hype/buzzwords**: Position as elite coaching and athletic tracking.
3. **Color discipline**: Obsidian dark base, Electric Sky Blue (`#38bdf8`) accents, Slate/Carbon cards, Green (`#22c55e`) strictly for completed sets.
4. **Layout discipline**: 1140px main container, 800px text container.
5. **Pricing**: ₹99 first month introductory hook, ₹399/mo ongoing renewal.
6. **SEO Head Terms**: Never target head terms (`take home pay calculator`, `mortgage calculator`) head-on against entrenched giants; target long-tail, wage tiers ($20, $25, $30, $35/hr), and state tax variants.
7. **Brand Defense**: Defend exact brand & domain queries (`socialninjas.in`, `social ninja's agency`) — never chase generic game/entertainment keywords.
8. **Zero AI Filler**: Every post must target 1 verified keyword, satisfy 1 search intent, and conclude with a specific service/tool CTA.
9. **Zero Link Schemes**: Never buy links or use PBNs. Build authority via data studies, tool embeds, and genuine digital PR.
10. **Cadence Discipline**: Minimum 2 strategic posts/month to prevent algorithmic decay. Run Rich Results Test on all new pages.
